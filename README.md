# Fact-Based Chatbot App

A web-based chatbot that answers questions based only on a custom list of facts provided by the user. Built with React (frontend) and NodeJS (backend), using the OpenAI Chat Completions API for natural language generation.

## Getting started

### Environment variables
#### Backend
``OPENAI_API_KEY``

``PORT``

#### Frontend
``REACT_APP_SERVER_URL``

### Install dependencies
```pnpm install```

### Run
```pnpm start```
